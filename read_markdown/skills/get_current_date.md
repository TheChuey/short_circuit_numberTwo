# Skill: get_current_date

## Purpose

Returns the real current date as a formatted string.

## When to Use

- When the user asks "what day is it?"
- When timestamping files or logs
- When the agent needs to know the current date for calculations
- When generating date-based content

## Parameters

None.

## Example

```
get_current_date()
```

Returns something like: `Wednesday, August 19, 2026`

## Returns

- A formatted date string

## Related Skills

- `tell_me_the_date_and_time`: Returns both date and time together
