# Skill: tell_me_the_date_and_time

## Purpose

Returns the current date and time.

## When to Use

- When the user asks "what time is it?"
- When timestamping operations
- When the agent needs both date and time together
- When logging events with timestamps

## Parameters

None.

## Example

```
tell_me_the_date_and_time()
```

Returns something like: `The current date and time is 2026-08-19 18:30:00`

## Returns

- A string with the current date and time

## Related Skills

- `get_current_date`: Returns only the date (no time)
